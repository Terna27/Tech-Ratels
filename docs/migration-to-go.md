# Backend Technology Migration Plan: Python/FastAPI to Go

## Context & Rationale

Per architectural directive, the entire backend of the Nigerian Ratels Management System has been converted from Python (FastAPI, SQLAlchemy, Alembic) to **Go (Golang)** with:
- Standard `net/http` package with `go-chi/chi/v5` router.
- Native PostgreSQL connection pooling and transactions using `jackc/pgx/v5`.
- Compile-time type-safe query generation using `sqlc`.
- Versioned, database-native schema migrations using `pressly/goose/v3`.
- Go standard `testing` framework for automated verification.
- Preserved Next.js 15, React 19, and TypeScript frontend with identical REST contract compatibility.

## Migration Steps Executed

1. **Schema Preservation & PostgreSQL Native DDL**:
   - Converted SQLAlchemy object models into clean, standard PostgreSQL schema DDL managed by `goose`.
   - Guaranteed table names, UUID primary keys, indices, and constraints (`uq_campaign_year_month`, `uq_event_user_registration`, `uq_event_user_participation`, `uq_user_badge_award`) match the product specification.

2. **Removal of Python Artifacts**:
   - Completely pruned `apps/api/src/`, `apps/api/tests/`, `apps/api/alembic/`, `requirements.txt`, and virtual environments to prevent competing or orphaned backend implementations.

3. **Go Module & Domain Packaging**:
   - Initialized Go module `ratels-api` in `apps/api/`.
   - Organized entry points under `cmd/` (`cmd/server` for HTTP daemon, `cmd/seed` for reference data population).
   - Structured core domain logic under `internal/`:
     - `internal/config/`: Configuration management.
     - `internal/db/`: Typed database models and queries generated by `sqlc`.
     - `internal/security/`: Bcrypt password hashing & JWT tokens.
     - `internal/delivery/`: Dev-safe contact verification delivery adapter.
     - `internal/calendar/`: Africa/Lagos monthly cleanup calculation.
     - `internal/service/`: Business rules (anti-self-approval, scoped RBAC, draft/published gate, capacity locking).
     - `internal/handler/`: Thin Chi HTTP handlers and middleware.

4. **Preservation of Frontend**:
   - The Next.js frontend (`apps/web`) communicates via `/api/v1/*` using JSON payloads.
   - All response schemas (including error envelopes `{"error": {"code": "...", "message": "..."}}`) match the existing client interfaces in `apps/web/src/lib/api.ts`.

5. **Tooling & Infrastructure Updates**:
   - Updated `infra/Dockerfile.api` to multi-stage Go compilation (`golang:1.22-alpine` -> `alpine:latest`).
   - Updated `scripts/start_dev.sh` and `scripts/run_tests.sh` to run Go builds, Goose migrations, seed commands, and `go test`.
